## How to practice a design question

1. Clarify functional and non-functional requirements.
2. Estimate scale, traffic, storage, and key constraints.
3. Identify APIs, data model, and core domain objects.
4. Draw the high-level components and data flow.
5. Discuss consistency, availability, caching, messaging, and failure handling.
6. Explain bottlenecks, observability, security, and trade-offs.
7. Deep dive into one critical component.

Focus on explaining *why* a design fits the requirements, not just naming technologies.

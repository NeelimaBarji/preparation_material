## Suggested workflow

1. Define target roles and non-negotiable requirements.
2. Compare each job description with the current resume and evidence of experience.
3. Identify skill gaps and prioritize practical learning.
4. Tailor application materials truthfully to the role.
5. Track applications, follow-ups, and outcomes.

**Privacy and safety:** Keep personal contact details, account credentials, API keys, private recruiter messages, and employer/client-confidential information out of public commits. Review generated application content before sending it.

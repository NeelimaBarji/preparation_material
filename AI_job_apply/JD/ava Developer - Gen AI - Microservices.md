# JD:

## Key Responsibilities
- Backend: Design and deploy high-throughput microservices using Java 11/17, Spring Boot, and RESTful APIs.
- Frontend: Develop interactive user interfaces using React or Angular (TypeScript, HTML5, CSS3).
- Gen AI Integration: Connect LLM capabilities (OpenAI APIs, LangChain4j, Spring AI) and implement RAG (Retrieval-Augmented Generation) patterns for smart backend workflows.
- Cloud & Microservices: Deploy applications on AWS (EC2, S3, CloudWatch) using Docker and Kubernetes.
- Data & Messaging: Optimize relational databases (MySQL, PostgreSQL) and build asynchronous streaming using Apache Kafka.

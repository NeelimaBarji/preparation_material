## Suggested practice loop

1. Identify the pattern and state the brute-force approach.
2. Improve the time/space complexity and explain the trade-off.
3. Implement a clean Java solution.
4. Test edge cases and explain complexity.
5. Revisit the problem after a few days without looking at the solution.

## Interview-ready checklist

- Explain the invariant or key observation before coding.
- State time and space complexity.
- Cover empty input, duplicates, boundaries, and overflow where relevant.
- Prefer readable names and small methods.
- Compare alternative approaches when there is a meaningful trade-off.
